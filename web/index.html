1. OpenAI-Compatible API (/v1/chat/completions)

Endpoint standar OpenAI. Cocok untuk Cursor, Cline, Roo Code, LibreChat, dan 9Router:

curl -X POST http://localhost:8990/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-deepseek4free" \
  -d '{
    "model": "deepseek-reasoner",
    "messages": [
      {"role": "user", "content": "Halo DeepSeek R1!"}
    ],
    "stream": true
  }'
2. Anthropic / Claude Messages API (/anthropic/v1/messages)

Mendukung format pesan Anthropic Claude (header x-api-key atau Authorization: Bearer):

curl -X POST http://localhost:8990/anthropic/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: sk-deepseek4free" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "deepseek-reasoner",
    "messages": [
      {"role": "user", "content": "Halo dari Claude API format!"}
    ],
    "max_tokens": 4096,
    "stream": true
  }'
3. Konfigurasi 9Router & Cursor / Cline
Integrasi ke Cursor IDE:
  1. Buka Settings di Cursor → Models.
  2. Di bagian OpenAI API Key, masukkan sk-deepseek4free.
  3. Aktifkan Override OpenAI Base URL dan isi dengan: http://localhost:8990/v1
  4. Tambahkan model baru bernama: deepseek-reasoner dan jadikan default.
Integrasi ke 9Router Combo Fallback:

Tambahkan node DeepSeek4Free ke konfigurasi 9Router sebagai primary reasoner:

{
  "provider": "openai",
  "name": "deepseek4free-r1",
  "baseUrl": "http://localhost:8990/v1",
  "apiKey": "sk-deepseek4free",
  "model": "deepseek-reasoner",
  "priority": 1,
  "weight": 100
}
4. Contoh Pemanggilan Python (OpenAI SDK) 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8990/v1",
    api_key="sk-deepseek4free"
)

response = client.chat.completions.create(
    model="deepseek-reasoner",
    messages=[{"role": "user", "content": "Jelaskan cara kerja multi-account pool."}],
    stream=True
)

for chunk in response:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)

Cara Mengaktifkan Auto-Deploy Instan di GitHub:
  1. Buka repositori Anda di GitHub → Settings → Webhooks → klik Add webhook.
  2. Paste URL di atas ke kolom Payload URL.
  3. Pilih Content type: application/json.
  4. Pilih Just the push event, lalu klik Add webhook.
  5. Selesai! Setiap Anda push commit ke GitHub, VPS akan otomatis menarik kode terbaru, menginstal library baru, dan me-restart server dalam hitungan detik tanpa downtime!
